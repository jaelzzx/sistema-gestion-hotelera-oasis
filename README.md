# 🏨 Sistema de Gestión de Base de Datos - Hotel Oasis

Proyecto desarrollado para el curso de **Base de Datos** en la **Universidad de Ciencias y Humanidades (UCH)**. Su objetivo principal es automatizar y centralizar los procesos de recepción, control de inventario de habitaciones, matriz de tarifas y auditoría financiera de egresos de un hospedaje familiar.

---

## 🚀 Características Principales
- **Modelo Relacional Normalizado (3FN):** Estructura limpia libre de redundancias y anomalías de actualización.
- **Matriz Comercial Indexada:** Cruce automático entre tipo de habitación, equipamiento (amoblada/sin amoblar) y modalidad de tiempo (3 horas, 12 horas, mensual).
- **Objetos Programables Avanzados:**
  - **Vistas (`VIEW`):** Para consultar la ocupación actual en tiempo real y el resumen de gastos.
  - **Procedimientos Almacenados (`Stored Procedures`):** Optimización de consultas repetitivas de clientes y catálogos.
  - **Disparadores (`Triggers`):** Auditoría automática en tiempo real para el registro de nuevos clientes y egresos de caja.

---

## 🛠️ Tecnologías Utilizadas
- **Motor de Base de Datos:** SQL Server / MySQL
- **Herramienta de Gestión:** SSMS / MySQL Workbench
- **Modelado:** Diagrama Entidad-Relación (DER)
